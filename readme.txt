ONIKA — интернет-магазин на PHP
==============================

Каталог одежды, обуви и аксессуаров с корзиной, оформлением заказов, личным
кабинетом покупателя и полноценной админ-панелью.
Языки: украинский (по умолчанию), русский, английский.
Без Node.js, без Composer, без MySQL: нужен только PHP 8.1+ и файл базы SQLite.


БЫСТРЫЙ СТАРТ НА XAMPP (Windows)
--------------------------------
1. Установите XAMPP (PHP 8.1 или новее) и запустите Apache в XAMPP Control Panel.
   MySQL запускать НЕ нужно.
2. Распакуйте архив  onika-xampp.zip  в папку  C:\xampp\htdocs\
   Получится папка  C:\xampp\htdocs\onika\
3. Откройте в браузере:
       Магазин:  http://localhost/onika/
       Админка:  http://localhost/onika/admin
4. Логин админа:  admin      Пароль:  onika2024
   При первом входе панель потребует сменить пароль — без этого она не откроется.
5. При первом запуске создаётся база данных (1–2 секунды), а миниатюры фото
   создаются по мере просмотра страниц. Дальше всё отдаётся мгновенно.

Не запускается? В XAMPP Control Panel: Apache -> Config -> PHP (php.ini). Убедитесь,
что в начале строк нет знака «;»:  extension=pdo_sqlite, extension=sqlite3,
extension=gd, extension=mbstring, extension=fileinfo. Затем перезапустите Apache.
Страница с ошибкой сама подскажет, чего не хватает.

Можно положить сайт в корень: распакуйте содержимое папки onika прямо в
C:\xampp\htdocs\ — тогда адрес будет http://localhost/

English quick start: install XAMPP (PHP 8.1+), unzip onika-xampp.zip into
C:\xampp\htdocs\, start Apache, open http://localhost/onika/ (admin panel:
/onika/admin, login admin / onika2024, you must change the password on first login).


ДРУГОЙ ХОСТИНГ / LINUX
----------------------
Нужно: PHP 8.1+ (pdo_sqlite, gd с поддержкой WebP, mbstring, fileinfo), Apache с
mod_rewrite и AllowOverride All (используется .htaccess). Загрузите папку на
хостинг и дайте PHP право записи в data/, uploads/ и media/.
Nginx: отправляйте все несуществующие файлы на index.php и закройте доступ к
папкам app/, data/, lang/, tools/ и к файлам config*.php.

Локально без Apache:   php -S localhost:8080 index.php


ЧТО ВНУТРИ
----------
index.php        точка входа (роутер)
app/             код приложения (PHP; шаблоны страниц — app/views)
lang/            переводы интерфейса (uk, ru, en)
assets/          CSS, JS, шрифты, иконки
images/          фото товаров
uploads/         фото, загруженные через админку
media/           миниатюры (создаются автоматически, папку можно очищать)
data/onika.db    база данных SQLite (создаётся при первом запуске)
data/seed/       стартовый каталог (338 товаров, 20 категорий, 25 брендов)
data/backups/    резервные копии базы
config.php       настройки по умолчанию (свои — в config.local.php)


ВОЗМОЖНОСТИ
-----------
Магазин
* Каталог: фильтры (категории, бренды, цена, наличие) без перезагрузки страницы,
  сортировка, живой поиск в шапке, «показать ещё», человекопонятные адреса.
* Карточка товара: галерея с увеличением, размеры, избранное, «недавно смотрели».
* Корзина и избранное хранятся в браузере; цены и наличие всегда проверяет сервер.
* Оформление заказа (Нова пошта, курьер, самовывоз; наложенный платёж / карта),
  страница заказа со статусом, личный кабинет, история заказов.
* Светлая и тёмная тема, адаптивный дизайн, SEO (sitemap.xml, hreflang, Schema.org).

Админ-панель (/admin)
* Дашборд с графиком продаж.
* Товары: загрузка фото и сортировка перетаскиванием, автоперевод на RU/EN,
  скрытие, наличие, корзина удалённых. Категории, бренды.
* Заказы (статусы, история, заметки), клиенты (сброс пароля), подписчики (CSV),
  сообщения из формы «Контакты».
* Настройки (тексты на 3 языках, контакты, порог бесплатной доставки) и
  резервные копии базы: создать / скачать / восстановить.


БЕЗОПАСНОСТЬ
------------
* Смените пароль админа при первом входе (панель этого требует).
* Пароли хранятся как bcrypt-хэши, формы защищены CSRF-токенами, число попыток входа
  ограничено, загружаемые фото перекодируются, папки app/, data/, lang/ закрыты
  для веб-доступа (.htaccess).
* Свои настройки храните в config.local.php (он не попадает в git).
* Не публикуйте содержимое data/ (там заказы и клиенты) и делайте резервные копии.


ПЕРЕНОС ДАННЫХ
--------------
Все данные лежат в двух местах: data/onika.db (товары, заказы, клиенты, настройки)
и uploads/ (загруженные фото). Скопируйте их — и сайт переедет на другой компьютер.
